# Support

Thanks for using Invitely.gg! Here's how to get help.

## 💬 Questions, ideas, "how do I…?"

Use **[GitHub Discussions](https://github.com/Vinodbiradar09/Invitely.gg/discussions)** — it's the right place for:

- Setup / self-hosting questions
- Feature ideas you want to chat through before opening an issue
- Show & tell ("here's how I'm using Invitely…")
- Architectural / design discussions

## 🐛 Bug reports

Use the **bug-report issue template** when something is genuinely broken or behaves unexpectedly:

→ [File a bug report](https://github.com/Vinodbiradar09/Invitely.gg/issues/new?template=bug_report.yml)

The more reproducible the steps, the faster we can fix it. Screenshots, error messages, and your environment (browser/OS/commit SHA) all help.

## 🌱 Feature requests

Open a **feature request** when you have a concrete improvement in mind:

→ [Suggest a feature](https://github.com/Vinodbiradar09/Invitely.gg/issues/new?template=feature_request.yml)

If you're unsure whether something is worth requesting, start a Discussion first.

## 🔒 Security vulnerabilities

**Do not file a public issue.** Email **security@invitely.gg** instead. See [SECURITY.md](./SECURITY.md) for our disclosure policy.

## ⏱️ Response times

This is an open-source project maintained on best-effort time. Expect:

- **Bug reports**: triaged within a week
- **Pull requests**: first review within two weeks
- **Security reports**: acknowledged within 48 hours

If something is genuinely urgent (production outage, data risk), escalate via the security email.

## 💚 Get involved

Want to do more than report? See [CONTRIBUTING.md](./CONTRIBUTING.md) — issues labelled `good first issue` are a friendly place to start.
